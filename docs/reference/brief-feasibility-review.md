# SAT Progress Tracker — Brief Review

What we have, what we will add, and what we need from you. Prepared by Sneha, 7 November 2026.
The same report as `SAT-Tracker-Brief-Review.docx`.

**Most of the brief is already built.** Three things are new: a student account (with the parent
report inside it), Bluebook results, and a rule for deleting old data.

**Everything will be ready by Tuesday, 10 November.** The only exception is adding OnePrep
questions. OnePrep blocks copying and downloading, so each question is copied by hand from a
screenshot, and that takes longer.

## 1. What we have today

| What the brief asks for | What we have today | Status |

| Enough questions for each skill | Only one skill has enough questions for a 10–15 question test. | Partly |

## 2. What we will add

| Update | How it will work |
| --- | --- |
| Student account | The test link stays the same. It still shows on the dashboard and can be shared directly. When opened, it asks for the student ID. That is the login. Inside, the student sees their tests and progress. |
| Parent report | A simple visual page inside the student's account. Parents open it with the student ID, so they need no login of their own. It shows the headline (e.g. "Writing 2/15 → 5/15"), a red / amber / green skill map and the trend. Easy to screenshot. |
| Score right after the test | The student sees the score and the missed skills as soon as the test ends. |
| Test size and timer | 10–15 questions, about 1 minute each. |
| OnePrep questions | Take a screenshot, pull out the text, check it, tag it, and add it to the bank, one skill at a time. |
| Practice links | Add Khan Academy, Bluebook, OnePrep and UWorld. |
| Deleting old data | Inactive data is deleted on its own after the agreed time. |
| Bluebook results (if wanted) | The tutor types in full-length Bluebook scores. They show next to the student's progress. |
| Skip button (if wanted) | The student can skip a question, and skips show in the insights. |
